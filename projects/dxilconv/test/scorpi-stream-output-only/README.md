The fixture is generated by Scorpi's `tools/fl11-probe` stream-output-data case
(`GeneratedGeometryShader(2, false, true)`, geometry=1, mode=1). It contains
our probe's SM5 geometry shader token stream and the DDI signature supplied by
Windows for `D3D11_SO_NO_RASTERIZED_STREAM`: three inputs, no outputs.
The source lives in scorpi-win-display-drv/tools/fl11-probe/common.h.

Run `python3 test.py <DXC-build-directory>` after building scorpi-dxbc-probe and dxc.
The same token stream must fail with an ordinary missing rasterized output
signature and convert with the explicit stream-output-only flag. This test also
checks the actual typed stores in the generated DXIL and invalid metadata flags.
GPU bit-for-bit output is checked by the separate Windows stream-output probes.
